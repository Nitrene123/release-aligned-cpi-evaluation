# Held-out RAE fault-generalization experiment

This folder contains an independently generated, case-held-out suite and a seeded property-based/metamorphic test harness for a frozen RAE checker snapshot. The suite is synthetic and target-free. It is not an external or third-party blind challenge.

## Results

- Held-out cases: 200 (50 clean, 120 single-fault, 30 composite).
- Faulted cases detected: 138/150 (92.0% recall); precision 100%; clean-control false-positive rate 0/50.
- Twelve missed single-fault cases involve transitive dependency edges that the frozen checker schema does not read. Six composite cases also contain that missed dependency component, although another fault in each case triggered an alarm.
- Property/metamorphic trials: 500/500 passed across four stated properties, using 625 checker executions.

See `RESULTS.md` for the full design, definitions, and interpretation.

## Reproduce

Run from this directory in a working copy:

    python generator/generate_heldout_suite.py
    python runner/run_property_tests.py
    python runner/run_heldout_suite.py

The generator does not import the checker. The separate runner loads frozen_rae/pit_audit.py and verifies it against freeze_receipt.json. Do not edit that checker when attempting to reproduce the reported run. The generator writes the truth manifest before audit execution. The runner compares audit outputs to that independent manifest.

The property harness uses deterministic random.Random generation from the Python standard library; Hypothesis was unavailable in the recorded environment. The finite suite does not claim exhaustive coverage or counterexample shrinking.

cases/ and results/heldout_truth.json are regenerated by the generator. Rebuild only in a working copy. results/heldout_case_results.csv, results/heldout_family_results.csv, and results/heldout_generalization_summary.json are the archived results. SHA256SUMS.txt covers every other file in this experiment folder.

# Partial Brent-vintage diagnostic: scoring contract

Score the sealed strict and partial-Brent-vintage forecasts on the same 99 target--origin keys per horizon used in the archived thirteen-method China comparison. Use the original B3 signed forecast-minus-target residual as a derived scoring input. For each matched key, compute the partial-vintage signed residual as the original B3 signed residual plus the partial-vintage forecast minus strict-replay forecast; take its absolute value and square for MAE and RMSE. This calculation does not require opening or exporting target values. Before scoring, require exact key and timestamp agreement and agreement between the archived absolute loss and the absolute signed residual within 1e-7 percentage points.

Report MAE, RMSE, mean and median paired loss change, direction counts, changed-forecast count, and sample ranking among the thirteen methods at each of h=1, 3, 6, and 12. Only B3's input varies; the twelve reference methods retain their archived predictions. Reproduce the pointwise 95% descriptive circular-block intervals using the complete monthly target calendar, 30,000 draws, seed 417, and block lengths 3, 6, and 12 months. Keep missing positions in the calendar and average the present losses in each draw.

The forecast archive, source model scores, map, inference metadata, this contract, and the scoring code are hashed in the results manifest. No P1 inputs, outcomes, or scores are accessed. The diagnostic is retrospective and concerns a single feature with incompletely observed revision histories; it is not the full four-protocol comparison.

# Partial Brent vintage diagnostic

For the archived B3 snapshots, compare the strict input with a separate variant that replaces only already-observed Brent year-on-year cells by the latest version captured in the available historical vintage registry. Select that version by its recorded availability timestamp, require the original cell's vintage identifier and value to match the registry, and apply a replacement only when the captured later version is available strictly after the forecast origin and differs numerically. Join by the input's source reference month, preserve every mask and all other inputs, and record excluded, ambiguous, and unchanged cells. The registry's captured latest version is not asserted to be the final version or a complete revision history.

Use the same official frozen checkpoint, source commit, 157-context batching order, decoding settings, and q50 parity check as S11. Generate and seal forecasts without reading scoring targets. On the previously used 99 common keys per horizon, compare absolute and squared errors and pointwise paired block intervals with the same calendar and bootstrap specification in `PROTOCOL.md`; source targets are not changed. Model-ranking sensitivity changes B3 only and keeps the other twelve archived methods fixed. This is a post-score, single-feature partial vintage sensitivity diagnostic, not the full four-protocol ablation.
